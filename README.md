## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Savannah001/Digital-Design.git

# Navigate to the project directory
cd Digital-Design

# Install dependencies
npm install
```

### Usage

```bash
# Start the development server
npm start

# Build for production
npm run build

# Run tests
npm test
```
